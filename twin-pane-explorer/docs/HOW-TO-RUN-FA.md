# چطور از Twin-Pane Explorer استفاده کنم؟

## 😤 اگر عجله داری — سه خط، همین

**در Termux** (برای خود برنامه‌ی دو-پنلی):

```bash
curl -fsSL https://github.com/HaadiTaba111/-/raw/main/twin-pane-explorer/scripts/termux-install.sh | bash
```

همین. کلون می‌کند، پایتون و git را نصب می‌کند، دسترسی حافظه می‌گیرد، برنامه را
نصب می‌کند، تست می‌کند و **خودش اجرا می‌شود**. از این به بعد فقط بنویس `twinpane`.

**APK** (برای مرور پوشه‌های گوشی بدون ترمکس): از همین ریپو نصب کن، دکمه‌ی آبی
**Browse phone files** را بزن. کار می‌کند، حتی اگر ترمکس نصب نباشد.

> اگر `curl` نداشتی: `pkg install -y curl` بعد خط بالا را دوباره بزن.
> بدون curl هم می‌شود: `git clone --depth 1 https://github.com/HaadiTaba111/-.git ~/twinpane-src && bash ~/twinpane-src/twin-pane-explorer/scripts/termux-install.sh`

## 👆 لمس: نوار دکمه‌ها و منوی پروژه (v1.4.0)

روی گوشی کلید `F` نداریم، پس نوار پایین حالا **دکمه‌های واقعی لمس** است:

```
┌─────────────────────────────────────────┐
│  Help  Rfr  View  →Copy  Move           │   ← ردیف ۱
│  Dir   Del  Proj  Menu   Quit           │   ← ردیف ۲ (زیر ۶۰ کاراکتر)
└─────────────────────────────────────────┘
```

روی ترمینال پهن، همه در یک ردیف جا می‌شوند. هر دکمه با انگشت کار می‌کند —
هیچ `F1`…`F10` لازم نیست.

### نوار پروژه

وقتی وارد پوشه‌ای می‌شوی که پروژه است، یک نوار بالای دکمه‌ها ظاهر می‌شود:

```
my-api  fastapi  git:main                              ▶ run
```

- **`▶ run`** بزن → سرور بالا می‌آید
- وقتی در حال اجراست: `● run :8000` — بزن → منوی پروژه باز می‌شود
- تشخیص خودکار از روی فایل‌ها:

| فایل | نوع | دستور |
|---|---|---|
| `manage.py` | Django | `runserver` |
| `next.config.*` | Next.js | `npm run dev` |
| `vite.config.*` | Vite | `npm run dev` |
| `requirements.txt` + FastAPI | FastAPI | `uvicorn` |
| `package.json` | Node | `npm run dev` / `npm start` |
| `docker-compose.yml` | Docker | `docker compose up` |
| `go.mod` / `Cargo.toml` | Go / Rust | `go run .` / `cargo run` |

اگر `.venv/` داشته باشد، از همان پایتون استفاده می‌کند.

### پروژه خودش را معرفی کند

در ریشه‌ی هر پروژه یک فایل `twinpane.project` بگذار:

```json
{"run": "uvicorn main:app --host 0.0.0.0 --port %(port)d", "port": 8000}
```

`%(port)d` با پورت انتخاب‌شده جایگزین می‌شود.

### منوی `Proj` — همه‌چیز با انگشت

- **Run** / **Stop** پروژه‌ی پوشه‌ی جاری
- **Show the log** (اسکرول‌شدنی)
- **Change its port / run command**
- **Check for a newer version (git)** / **Update now**
- **Clone a git repository here**
- **Open ports** — لیست همه‌ی پورت‌های باز
- **All projects I have started**

### مدیریت پورت — جواب کش مرورگر

منوی `Proj` → **Open ports**:

```
:8000  my-api              running
:3000  (something else is using it)
:5173  web                stopped
```

روی هر پورت بزنی: **آزاد کن** · **پورت را عوض کن** · **کپی لینک**

«پورت را عوض کن» پروژه را روی پورت آزاد بعدی بالا می‌آورد و در
`twinpane.project` ذخیره می‌کند. **بدون پاک‌کردن کش مرورگر.**

اگر پورت درخواستی مشغول باشد، خودش پورت آزاد بعدی را انتخاب می‌کند و می‌گوید.

### ماوس در ترمکس حالا خاموش است

قبلاً ماوس/لمس روشن بود و با کیبورد ترمکس تعارض داشت (صفحه قفل می‌شد).
حالا در ترمکس **پیش‌فرض خاموش** است. اگر خواستی: `twinpane --mouse`

## ↕️ مرتب‌کردن فایل‌ها با یک لمس (v1.4.1)

روی نوار پایین، دکمه‌ی **`Sort`** اضافه شده. هر بار که می‌زنی، ترتیب عوض می‌شه:

| لمس | نتیجه |
|---|---|
| ۱ بار | بر اساس **نام** (A→Z) |
| ۲ بار | بر اساس **نام** (Z→A) |
| ۳ بار | بر اساس **تاریخ** (قدیمی‌ترین اول) |
| ۴ بار | بر اساس **تاریخ** (جدیدترین اول) |
| ۵ بار | بر اساس **حجم** (کوچک‌ترین اول) |
| ۶ بار | بر اساس **حجم** (بزرگ‌ترین اول) |
| ۷ بار | برمی‌گرده سر «نام A→Z» |

انتخابت **ذخیره می‌شه**؛ دفعه‌ی بعد که برنامه رو باز کنی، همون ترتیبی که گذاشتی می‌مونه.

**مرتب‌سازی کامل‌تر (انتخاب نوع و جهت):**
`Menu` → **`Sort this panel`** → با `↑`/`↓` روی گزینه‌ها برو، روی سرستونِ فعلی یه `▲`/`▼` هست که نشون می‌ده الان چه ترتیبی داری. بعد `Enter`.

> هر پنل ترتیب **خودش** رو داره؛ اگه پنل چپ رو بر اساس تاریخ مرتب کنی، پنل راست دست‌نخورده می‌مونه.

**پوشه‌ها همیشه بالای لیست می‌مونن** — این رفتار عوض نمی‌شه.

## 🔧 چه چیزهایی در ۱.۴.۱ درست شد

- **`Sort` روی نوار لمس** — قبلاً مرتب‌سازی فقط از منو و با کیبورد بود؛ الان با یک لمس.
- **پل ترمکس دیگه بی‌صدا توی پوشه‌ی نامرئی اجرا نمی‌شه** — اگه دسترسی به حافظه‌ی گوشی نداشته باشی، با پیام واضح می‌گه چه‌کار کنی و متوقف می‌شه.
- **نصب‌کننده بعد از «نه» گفتن به دسترسی حافظه ادامه نمی‌ده** — قبلاً رد می‌شد و بعداً خرابی می‌داد؛ الان صبر می‌کنه، دوباره چک می‌کنه و اگه نشد با پیام قرمز واضح می‌گه «termux-setup-storage» رو بزن.
- **اپلیکیشن اندروید دقیقاً می‌گه چی خرابه** — به جای «کار نمی‌کنه»، می‌گه مثلاً «پوشه‌ی پل در دسترس نیست» یا «worker.json قدیمی‌تر از ۱۵۰ ثانیه است» و کنارش دکمه‌ی **`Copy the fix`** هست که دستورش رو کپی می‌کنه.
- **نوار دکمه‌های گوشی مرتب شد** — آیکون `→Copy` فاصله‌ی دکمه‌ی بغلی رو خراب می‌کرد؛ الان همه‌ی دکمه‌ها دقیقاً به لبه می‌رسن و هیچ دکمه‌ای از صفحه بیرون نمی‌افته.
- **اسم برنامه دیگه نصف نمی‌شه** — قبلاً روی گوشی می‌شد `Twin-Pane Ex`. الان کامل نوشته می‌شه.
- **نام دو پنل روی هم نمی‌افته** — راهنمای «Tab: next panel» دیگه روی اسم پنل دوم چاپ نمی‌شه.
- **منوی F9 درست کار می‌کنه** — یک جابه‌جایی باعث شده بود از آیتم «Switch layout» به بعد، هر ردیف دستور ردیف بغلی رو اجرا کنه. اصلاح شد و یک تست نگهبان اضافه شد.

## 🚀 راه اول (توصیه‌شده): نصب خودکار در Termux

یک دستور، همه‌چیز. اسکریپت خودش:

1. چک می‌کند داخل ترمکس هستی
2. `python` و `git` را اگر نبود نصب می‌کند
3. `termux-setup-storage` را صدا می‌زند (پنجره‌ی اندروید → **Allow**)
4. ریپو را **shallow** کلون می‌کند (`--depth 1`، حدود یک مگابایت)
5. برنامه را در `$PREFIX/lib/twinpane` نصب و `$PREFIX/bin/twinpane` را می‌سازد
6. یک تست واقعی می‌زند (zip/unzip روی فایل موقت)
7. برنامه را باز می‌کند

```bash
# نصب + اجرا
curl -fsSL https://github.com/HaadiTaba111/-/raw/main/twin-pane-explorer/scripts/termux-install.sh | bash

# گزینه‌های دیگر
... | bash -s -- --install     # فقط نصب
... | bash -s -- --update      # به‌روزرسانی کد و اجرا
... | bash -s -- --run         # فقط اجرا
... | bash -s -- --doctor      # عیب‌یابی محیط
... | bash -s -- --uninstall   # حذف
```

بعد از نصب:

```bash
twinpane          # اجرا
twinpane-update   # اگر اسکریپت نساختش: همان دستور نصب را دوباره بزن
```

## 🔗 پنل ترمکس در APK (چه چیزی لازم است)

نسخه‌ی ۱.۳.۰ یک **bridge** دارد: APK و ترمکس از طریق یک پوشه‌ی مشترک حرف می‌زنند.

**چرا؟** ترمکس هم `~` خودش را می‌بیند هم `/sdcard`. اپ اندروید فقط `/sdcard`.
پس هر جابجایی بین این دو، فقط از داخل ترمکس ممکن است. آینه‌کردن لیست کار
نمی‌کرد — یک اسم آینه‌شده را نمی‌شود کپی کرد.

### یک بار در ترمکس

```bash
twinpane-bridge
```

یا برای همیشه در پس‌زمینه:

```bash
sv-enable twinpane-bridge
```

### در APK

روی نوشته‌ی **PHONE** در پنل بزن → **Termux home** را انتخاب کن.

- چیپ زرد = پنل ترمکس، چیپ سبز = پنل گوشی
- کپی/انتقال/حذف/پوشه‌سازی از/به ترمکس از همان دکمه‌ها کار می‌کند
- اگر worker خاموش باشد، اپ **صادقانه می‌گوید** و دکمه‌ی کپی دستور می‌دهد
- پنل‌های گوشی هیچ‌وقت به worker نیاز ندارند

### مسیر فنی

```
/sdcard/TwinPane/bridge/requests/<id>.json   ← اپ می‌نویسد
/sdcard/TwinPane/bridge/work/<id>.json       ← worker با rename برمی‌دارد
/sdcard/TwinPane/bridge/results/<id>.json    ← worker جواب می‌دهد
/sdcard/TwinPane/bridge/worker.json          ← ضربان قلب
```

بدون سوکت، بدون پورت، بدون root.

## 📱 راه دوم: APK اندروید

نسخه‌ی **1.1.1** دو کار می‌کند:

### الف) مرورگر فایل داخلی — بدون ترمکس

دکمه‌ی آبی **«Browse phone files (no Termux needed)»**:

- لیست واقعی پوشه‌های گوشی: `/sdcard`، Downloads، DCIM، Pictures، Music، Documents
- پوشه‌ها بالا، مرتب‌شده بر اساس نام
- اندازه و تاریخ هر فایل
- تپ روی فایل متنی → پیش‌نمایش؛ روی `.apk` → نصب
- نگه‌داشتن (long-press) → حذف
- دکمه‌ی `≡` → پرش سریع به پوشه‌های معروف

روی اندروید ۱۱+ یک بار «All files access» می‌خواهد — یک تپ، بعد همه‌چیز باز است.
اگر ندادی، پایین صفحه با یک نوار نارنجی می‌گوید چه کار کنی (به‌جای لیست خالی و سردرگمی).

### ب) راه‌انداز ترمکس

دکمه‌ی سبز **«Open the two-panel terminal»** — TUI را در ترمکس باز می‌کند.

اگر ترمکس نصب نباشد → پیشنهاد نصب از F-Droid.
اگر اجازه نداشته باشد → پنجره‌ی اجازه‌ی اندروید.
اگر ترمکس جواب ندهد → دکمه‌ی **Copy the command** برای چسباندن دستی.

**نکته‌ی مهم:** APK خودش مرورگر فایل دارد، پس **هیچ‌وقت صفحه‌ی خالی نمی‌بینی** —
حتی اگر کل ماجرای ترمکس خراب باشد.

### اگر ترمکس اجازه‌ی دستور نداد

در ترمکس:

```bash
echo "allow-external-apps=true" >> ~/.termux/termux.properties
termux-reload-settings
```

بعد دوباره دکمه‌ی سبز را بزن. (نسخه‌ی 1.1.1 علاوه بر این، payload را در
`/sdcard/Download/TwinPane/` هم می‌گذارد تا ترمکس بتواند بخواندش — نسخه‌ی
قبلی مسیر خصوصی `/data/data/...` را می‌داد که ترمکس اجازه‌ی خواندنش را ندارد.)
